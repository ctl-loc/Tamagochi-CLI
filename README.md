# Tamagochi CLI

Minimal CLI friend

## Built with
- C
- GCC 15.2.0

## Getting started

1. Clone the project
```shell
git clone https://github.com/ctl-loc/Tamagochi-CLI
cd Tamagochi-CLI
```

2. Build the project and play
```shell
make # creates the executable file
./bin/tamagochi # run the game

# Merged
make run
```
